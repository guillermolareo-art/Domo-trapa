# Domo-trapa ???

Panel web unificado (PWA) y backend ligero en Python para la gestión domótica integrada.

## Funcionalidades
- **Garaje / Cancela (FAAC 740):** Control de pulso y consulta de estado (sensor magnético Tuya).
- **Ecosistema Tapo:** Integración de cámaras y enchufes inteligentes.
- **PWA Móvil:** Interfaz web táctil optimizada para iOS y Android.

## Estructura
- /backend: Servidor Python (Flask) e integración con APIs (Tuya OpenAPI / Tapo).
- /frontend: Dashboard PWA táctil e instalable en dispositivos móviles.
